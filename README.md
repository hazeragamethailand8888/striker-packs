# STRIKER PACKS — เซิร์ฟเวอร์ออนไลน์

มี 2 ไฟล์หลัก: `server.py` (เซิร์ฟเวอร์ ใช้ Python ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม) และ `index.html` (ตัวเกม)

## ลองรันในเครื่อง
    python3 server.py
เปิด http://localhost:8000 แล้วสมัครสมาชิกได้เลย ข้อมูลเก็บในไฟล์ `game.db`

## เอาขึ้นเน็ตให้คนอื่นเข้าได้
เลือกที่ฝากอย่างใดอย่างหนึ่ง (ต้องมีที่เก็บไฟล์ถาวรสำหรับ `game.db` ไม่งั้นข้อมูลหายตอนรีสตาร์ต)
- **Render / Railway / Fly.io**: อัปโหลดโฟลเดอร์นี้ ใช้ `Dockerfile` ที่ให้มา แล้วต่อดิสก์ถาวรที่ `/data`
- **VPS (เช่น DigitalOcean, Vultr)**: รัน `python3 server.py` ใต้ systemd และใช้ Caddy หรือ nginx ทำ HTTPS ตั้ง `TRUST_PROXY=1`
- **ต้องใช้ HTTPS เสมอ** เพราะผู้เล่นพิมพ์รหัสผ่าน

ตัวแปรที่ตั้งได้: `PORT` (ค่าเริ่มต้น 8000), `DB_PATH`, `TRUST_PROXY=1` (เมื่ออยู่หลังพร็อกซี)

## สิ่งที่ระบบทำให้แล้ว
- สมัคร/เข้าสู่ระบบ (รหัสผ่านเข้ารหัส PBKDF2, จำกัดจำนวนครั้งที่ลอง, ชื่อห้ามซ้ำไม่สนตัวพิมพ์เล็กใหญ่)
- เซฟเกมบนเซิร์ฟเวอร์ เล่นข้ามเครื่องได้
- ตารางอันดับ ค้นหาผู้เล่น เพื่อน ท้าทีมจริง (คูลดาวน์ 30 นาทีต่อคู่, สูงสุด 30 ครั้งต่อวัน)
- เปลี่ยนชื่อ (ตรวจชื่อซ้ำที่เซิร์ฟเวอร์)

## ข้อจำกัดที่ควรรู้
- **กันโกงยังไม่ครบ**: ตรรกะเกม (เปิดซอง แข่ง เหรียญ) ยังรันในเบราว์เซอร์ คนที่รู้เรื่องโค้ดแก้ค่าของตัวเองได้ เซิร์ฟเวอร์ตรวจแค่ทีมตัวจริงต้องเป็นการ์ดที่มีจริง และจำกัดแต้มท้าต่อวัน
- ยังไม่มีระบบกู้รหัสผ่าน (ไม่มีอีเมล) ลืมรหัสต้องให้ผู้ดูแลแก้ในฐานข้อมูล
- ยังไม่มีการกรองชื่อไม่สุภาพ
- สำรองไฟล์ `game.db` เป็นประจำ

## ออนไลน์ด้วย Supabase + GitHub Pages (ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง)
1. สมัคร supabase.com (ล็อกอินด้วย GitHub ได้) กด New project ตั้งชื่อและรหัสผ่านฐานข้อมูล (จดไว้) เลือกภูมิภาค Singapore รอประมาณ 2 นาที
2. เมนูซ้าย SQL Editor แล้ว New query วางเนื้อหา `supabase.sql` ทั้งไฟล์ กด Run ต้องขึ้นว่าสำเร็จ (Success)
3. Project Settings แล้ว API: คัดลอก Project URL และคีย์แบบ anon public (หรือ publishable) **ห้ามใช้คีย์ service_role**
4. ใน repository ของเว็บ GitHub Pages: Add file แล้ว Create new file ชื่อ `config.json` เนื้อหา `{ "url": "ลิงก์โปรเจกต์", "key": "คีย์" }` (ดูตัวอย่างใน `config.example.json`) แล้ว Commit
5. อัปโหลด `index.html` อันใหม่ทับของเดิม
6. รีเฟรชเว็บ ถ้าช่องรหัสผ่านเขียนว่า "รหัสผ่าน (6 ตัวขึ้นไป)" แปลว่าเชื่อมออนไลน์แล้ว

ข้อควรรู้: โปรเจกต์ฟรีของ Supabase จะหยุดเองถ้าไม่มีใครเรียกใช้ 7 วัน (ข้อมูลไม่หาย แต่ต้องกด Restore ในหน้า Dashboard) แชตและแมตช์สดใช้การเช็กทุก 2-3 วินาที ไม่ใช่การเชื่อมต่อค้าง บัญชีที่สมัครไว้ในเครื่อง (โหมดไม่มีเซิร์ฟเวอร์) จะไม่ถูกย้ายมาอัตโนมัติ ต้องสมัครใหม่

## ส่วนเสริม v2 (รันหลัง supabase.sql สำเร็จเท่านั้น)
รันไฟล์ `supabase_v2.sql` ใน SQL Editor อีกครั้ง (แยกไฟล์เพื่อไม่ให้กระทบระบบหลักถ้ามี error) จะได้
- กันโกง: บัญชีที่เหรียญหรือการ์ดโตผิดปกติจะถูกติดธง ซ่อนจากอันดับและตลาด (ไม่ลบเซฟ)
- รหัสกู้บัญชีตอนสมัคร (ใช้ที่ "ลืมรหัสผ่าน?")
- ซีซันแรงค์รายเดือน (RP ลดครึ่งสิ้นเดือน ท็อป 10 รับเหรียญ)
- ตลาดผู้เล่น (ขายเฉพาะใบซ้ำ ค่าธรรมเนียม 5%)
- ขอเป็นเพื่อน/ตอบรับ และแชตส่วนตัว
- ประกาศและอีเวนต์จากเซิร์ฟเวอร์

### วิธีลงประกาศ/อีเวนต์ (Table Editor > news > Insert row)
- kind = news, cfg = {} : ขึ้นแบนเนอร์ที่หน้าแรก
- kind = coin_mult, cfg = {"mult": 2} : คูณรางวัลเหรียญจากแมตช์ (สูงสุด x3)
- kind = featured, cfg = {"ids": [10, 25, 90]} : กำหนดนักเตะเด่นของซอง EVENT (สูงสุด 6)
ใส่ title/body ตามต้องการ ตั้ง ends เป็นเวลาสิ้นสุด หรือปล่อยว่างถ้าไม่หมดอายุ

### ข้อจำกัดของกันโกง
เป็นการตรวจความผิดปกติ ไม่ใช่การย้ายตรรกะเกมทั้งหมดไปไว้บนเซิร์ฟเวอร์ คนที่โกงช้า ๆ ในปริมาณน้อยอาจไม่ถูกจับ

## v3: เศรษฐกิจฝั่งเซิร์ฟเวอร์ (กันโกงจริง) — รัน supabase_v3.sql หลัง v1 และ v2
หลังรัน v3 และอัปโหลด `index.html` ตัวใหม่ ระบบจะย้าย "เหรียญ การ์ดที่มี ระดับฝึก ตัวนับการันตี เหรียญอีเวนต์ ธนาคาร" ไปอยู่ในกระเป๋าฝั่งเซิร์ฟเวอร์
- เปิดซอง (รวมซองฟรี/สปิน/รางวัล), ขายใบซ้ำ, รวมการ์ด, ฝึกการ์ด, ตลาดมืด, โต๊ะแลก, ร้านอีเวนต์, ธนาคาร, ไอเทม, ค่าเข้าถ้วย/บอส, เปลี่ยนชื่อ, ตลาดผู้เล่น คำนวณและตัดเหรียญที่ฐานข้อมูลทั้งหมด
- แก้ค่าเหรียญหรือการ์ดในเบราว์เซอร์ไม่มีผล (เกมจะแสดงค่าจากเซิร์ฟเวอร์เท่านั้น)
- รางวัลจากแมตช์ ถ้วย ลีก มินิเกม ภารกิจ ฯลฯ: จำนวนเหรียญกำหนดที่เซิร์ฟเวอร์ (ตาราง rwd) มีคูลดาวน์และโควตา เช่น แมตช์ 10 นัดแรกต่อวันเต็มจำนวน นัดที่ 11-30 ได้ 20% หลังจากนั้นไม่ได้เหรียญ
- ผู้เล่นเดิมถูกย้ายเหรียญและการ์ดจากเซฟเก่าเข้ากระเป๋าครั้งแรกที่ล็อกอิน (บัญชีที่ถูกติดธงโกงเริ่มใหม่ที่ 1,000 เหรียญ)
- ในโหมดนี้โบนัสเหรียญตอนเลเวลอัปถูกยกเลิก (เลเวลยังอยู่ที่เครื่องผู้เล่น จึงไม่ใช้เป็นแหล่งเหรียญ)

ข้อจำกัดที่ยังเหลือ (พูดตรง ๆ)
- ผลแมตช์ยังจำลองในเบราว์เซอร์ ผู้เล่นที่รู้วิธีสามารถส่งคำขอ "ชนะ" ซ้ำได้ แต่ถูกจำกัดด้วยคูลดาวน์และโควตารายวันข้างต้น (ได้ไม่เกินราว 4,500 เหรียญต่อวันจากแมตช์)
- รางวัลแบบครั้งเดียว (เหรียญความสำเร็จ ชุดสะสม ซีซันพาส) เซิร์ฟเวอร์ยังไม่ตรวจเงื่อนไข คนโกงกดรับได้ครบครั้งเดียว รวมประมาณ 100,000 เหรียญตลอดชีพ และรางวัลรายสัปดาห์อีกประมาณ 9,000 ต่อสัปดาห์
- ไฟล์ SQL ผ่านการเขียนและตรวจด้วยตา ยังไม่เคยรันบน Postgres จริง ถ้ามี error ให้ส่งข้อความมา

- **โค้ดรางวัล**: ผู้เล่นใส่โค้ดที่หน้า "🎟 ใส่โค้ด" (หมวดความก้าวหน้า) หรือเปิดลิงก์ `.../index.html?code=โค้ด` จะกรอกโค้ดให้อัตโนมัติ โค้ดใช้ได้คนละ 1 ครั้ง
- **หน้าแอดมิน 🛠**: สร้างโค้ดโดยกำหนดเหรียญ ซอง (ชนิด x จำนวน) นักเตะที่ระบุ จำนวนสิทธิ์ วันหมดอายุ ระบบคัดลอกโค้ดหรือลิงก์ให้ ดูรายการและปิดโค้ดได้ เห็นเฉพาะบัญชีแอดมิน ลิงก์เข้าตรง: `.../index.html#admin`
- **ตั้งแอดมินครั้งเดียว** ใน SQL Editor (แทนชื่อผู้เล่นของคุณ):
  `insert into admins(uid) select id from users where lc = lower('ชื่อผู้เล่นของคุณ') on conflict do nothing;`
